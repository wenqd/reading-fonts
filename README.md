# reading-fonts

开源阅读 App（Legado）精选中文字体合集。字体均来自各官方开源项目，开源可免费商用。

> 📦 **下载：https://github.com/wenqd/reading-fonts/releases/download/v1.0/All-In-One.zip**（全部打包 84MB）
